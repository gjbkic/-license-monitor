## 本人情報を一度登録する

GitHub Repository → Settings → Secrets and variables → Actions → Secrets → New repository secret。

| Secret名 | 内容 |
| --- | --- |
| `DISCORD_WEBHOOK` | 本人が予約結果を受け取るDiscord Webhook URL。既存の設定を使用できます。 |
| `APPLICANT_JSON` | 下記JSONの空欄を本人の正式な情報に置き換えたもの。 |

```json
{
  "name_kana": "",
  "birth_date": "",
  "phone": "",
  "certificate_number": ""
}
```

- `name_kana`: 氏名。サイト指定のカナ表記。
- `birth_date`: 生年月日。`YYYY-MM-DD`。
- `phone`: 本人の連絡先。ハイフンなしの半角数字10〜11桁。
- `certificate_number`: 卒業証明書等に記載された正式な番号。予約後に発行される受付番号ではありません。

番号は先頭の0を保持するため引用符で囲みます。空欄、数値型、架空の初期値は使いません。
コード・チャット・workflowのinputsへ本人情報を直接書かず、Secretsへ登録してください。

## 検証と有効化

1. PRのブランチを選んで Actions → 本免キャンセル監視 → Run workflow → operation=`check_profile`。
   設定・形式だけを確認します。本人性や証明書の有効性を保証する確認ではありません。
2. Actions → 予約サイト接続診断で公式サイトの読込状態を確認します。
   PR変更でも診断が走ります。本人情報を送信したり規約へ同意したりしません。
3. 実サイトでの予約フォーム・遷移確認を終えてから、Repository variablesに
   `AUTO_RESERVE_ENABLED=true` と `BOOKING_TERMS_ACCEPTED=true` を設定します。
   後者は本人が公式利用規約を確認した場合のみ設定してください。
4. 手動ならoperation=`auto_reserve`。mainへ反映すると5分間隔の定期実行対象になります。
   定期実行は `AUTO_RESERVE_ENABLED=true` の場合だけ動きます。
   GitHub Actionsのscheduleは実行時刻が遅れる場合があります。

停止は `AUTO_RESERVE_ENABLED=false` に変更し、実行中のActionsがあれば停止してください。
実行が終わるまで次の実行から強制中断しない構成です。予約送信中の中断は結果不明になるため、
中断した場合は公式サイトで予約状況を確認してください。

## 全自動処理

1. 残席を発見した時点で「残席あり」をDiscordへ通知します。5秒後の再確認はしません。
2. 新しい予約手続を開き、登録された本人情報を入力します。
3. 対象の会場・日時を選び、確認画面の会場・日付・試験時刻・氏名・証明書番号を照合します。
4. 予約確定を1回送信します。
5. 予約完了画面と12桁の受付番号を確認した場合だけ「予約取得成功」として別途通知します。
   受付番号はDiscordへ送ります。個人情報や受付番号の平文は実行ログに出しません。
6. 取得成功後は新たな予約を作りません。成功通知の送信に失敗した場合は通知だけを再試行します。

結果不明の場合は `.booking_state.json` に `submitting` を残し、次回も再送しません。
公式サイトで予約の有無を確認してから対応してください。状態を削除しての強制再実行は避けてください。
既存の予約の取消し・別予約への差替えは行いません。

予約状態をキャッシュへ保存します。受付番号はDiscord Webhookから導出したキーで暗号化します。
Webhookを変更すると、以前の暗号化済み受付番号を復号できなくなります。
runnerの強制終了やキャッシュ保存失敗では状態が次回へ引き継がれない可能性があります。
この場合も、公式サイトの既存予約エラーを越えて再予約する処理はありません。

## PCで情報を保存する場合

```sh
python -m pip install -r requirements.txt
python -m playwright install chromium
python setup_applicant.py
```

端末で4項目を入力すると、PCの `applicant.local.json` に保存します。
入力文字は非表示です。保存ファイルは平文なので、他人が読めるフォルダに置かないでください。
Gitからは除外しています。GitHub SecretsはPCへ自動ダウンロードされません。
環境変数 `APPLICANT_JSON` があればローカルファイルより優先します。

入力補助だけを使う場合は `python autofill.py`。全自動は `python auto_reserve.py` で、
前述の環境変数（本人情報・Webhook・有効化フラグ・規約確認フラグ）を必要とします。
