# 本免キャンセル監視

府中・鮫洲・江東の学科試験について、明日から45日先まで残席を確認します。
残席を検知した時点でDiscordへ通知します。これは予約取得の通知ではありません。

## 現在の対応範囲

自動予約処理は未実装です。架空の氏名・電話番号・申込番号を本番に送信する機能はありません。
予約フォーム以降は実サイトで未検証のため、予約確定まで動作するとは保証していません。
自動定期実行は停止したままです。

## 手動実行

GitHubの Actions → 本免キャンセル監視 → Run workflow で実行します。
この修正を試す場合は実行するブランチを選択してください。
再実行時は古い失敗実行の Re-run ではなく、新しい Run workflow を使用してください。
Re-run は失敗当時の古いコミットを再利用します。

Repository secrets に `DISCORD_WEBHOOK` を登録します。
未登録の場合は標準出力だけに記録され、Discord通知は届きません。
`MONITOR_DAYS_AHEAD` は1〜90日で指定できます（通常45日）。

## 修正と確認

直近の失敗実行 `37013269027` は2026年10月2日、カレンダーが10月のときに固定の9月へ
戻ろうとして `ScanError: 2026/9へ移動できません` で停止していました。
最新版の動的期間計算を維持し、同じ問題を防ぐ回帰テストを追加しています。

- SPAの画面読み込みを待ってからクリックします。
- 午前・午後の別の枠から残席を読み取る誤検知を防ぎます。
- 全会場の確認完了を待たず、発見した残席を直ちに通知します。
- 1会場の通常の読取エラー後も他の会場を確認します。全体は失敗と記録します。
- アクセス制限を検知した回は成功扱いにせず停止します。
- Discordがエラー応答を返した場合も送信成功扱いにしません。
- 障害時は個人情報やページ本文・URLのクエリを含まない診断JSONをActions artifactに7日保存します。

```sh
python -m pip install -r requirements.txt
python -m unittest -v
python -m playwright install chromium --with-deps
python monitor.py
```

テストはモックで行います。実サイトへの予約・Discord送信は発生しません。
実サイトが白画面のままで予約フォームを取得できない状態では、残席や予約の成功を推測しません。
