# 本免キャンセル監視

府中・鮫洲・江東の学科試験について、明日から2026年12月31日まで残席を確認します。
残席を検知した時点でDiscordへ通知します。これは予約取得の通知ではありません。

## 現在の対応範囲

自動予約処理は未実装です。架空の氏名・電話番号・申込番号を本番に送信する機能はありません。
予約フォーム以降は実サイトで未検証のため、予約確定まで動作するとは保証していません。
自動定期実行は停止したままです。

## 手動実行

GitHubの Actions → 本免キャンセル監視 → Run workflow で実行します。
この修正を試す場合は実行するブランチを選択してください。
再実行時は古い失敗実行の Re-run ではなく、新しい Run workflow を使用してください。
Re-run は失敗当時の古いコミットを再利用します。

Repository secrets に `DISCORD_WEBHOOK` を登録します。
未登録の場合は標準出力だけに記録され、Discord通知は届きません。
`MONITOR_END_DATE` に終了日をYYYY-MM-DDで指定します（Actions設定は2026-12-31）。
指定がない場合は `MONITOR_DAYS_AHEAD` の日数を使います（1〜90日、通常45日）。
終了日を過ぎても翌年へ対象を自動延長しません。

## 本人情報の登録とフォームへの自動入力

予約後に発行される「受付番号」と、申込みに使う「卒業証明書等の番号」は別です。
入力するのは本人の正式な氏名（カナ）、生年月日、電話番号、卒業証明書等の番号です。

### PCで使う（実際にフォームに自動入力する方法）

このPRのブランチを取得したフォルダで、端末を開いて実行します。

```sh
python -m pip install -r requirements.txt
python -m playwright install chromium
python setup_applicant.py
python autofill.py
```

`setup_applicant.py` が4項目を順に尋ねます。入力文字は画面に表示されません。
本人情報はPCの `applicant.local.json` に保存します。これは平文のローカルファイルです。
Git対象から除外しています。共有フォルダや他人が読める場所には置かないでください。

`autofill.py` はブラウザを開きます。自分で規約の確認・手続区分の選択を行い、
予約者情報の入力画面を表示してから端末でEnterを押すと、保存した情報を入力します。
入力後はブラウザで確認し、会場・日時の選択、予約確定を行えます。
最後のEnterはブラウザを閉じるので、予約確定・受付番号等の保存を済ませてから押してください。

フォームの欄が対応付けられない場合は、推測して入力せず停止します。
現時点では実サイトのフォームを安定して取得できず、実サイトでの自動入力は未検証です。
生年月日がdate入力欄または年/月/日selectの形式を対象とします。
和暦・複数欄への氏名分割・生年月日の書式不明なテキスト欄は未対応です。
この機能はローカルPCで使用する入力補助です。Actionsでの自動予約はまだ行いません。

### GitHub Secretsに本人情報を登録する場合

Repository → Settings → Secrets and variables → Actions → New repository secret。
Secret名は `APPLICANT_JSON`。値は次のJSONの文字列を自分の正式な情報に置き換えます。
空欄のままでは検証に通りません。番号は先頭の0を保持するため必ず引用符で囲みます。

```json
{
  "name_kana": "",
  "birth_date": "",
  "phone": "",
  "certificate_number": ""
}
```

`birth_date` は `YYYY-MM-DD`、`phone` はハイフンなし半角数字です。
Actions → 本免キャンセル監視 → Run workflow → このPRのブランチを選択 →
operationで `check_profile` を選択すると、値をログに表示せず設定・形式だけを確認します。
本人性・証明書の有効性を保証する検証ではありません。予約や外部への送信は行いません。

GitHub Secretsの値はPCへ自動ダウンロードされません。PCで自動入力する場合は
上の `setup_applicant.py` で同じ本人情報をPCにも登録してください。
環境変数 `APPLICANT_JSON` が設定されている場合はローカルファイルより優先します。
値をコマンド引数に直接書くと端末履歴に残るため、対話入力で設定してください。
